# Main Description editor reference match

The Zelvomart admin product Main Description editor now uses the same editor structure and toolbar behavior supplied in the reference ProductForm code:

- Undo / Redo
- Paragraph, Heading 1, Heading 2, Heading 3
- Bold / Italic / Underline / Strikethrough
- Left / Center / Right / Justify
- Bullets / Numbered list
- Link / Unlink / Clear formatting
- Sticky toolbar
- 300px minimum editing surface, 640px max scrolling editor
- Selection-preserving link insertion
- Ctrl+Alt+1/2/3 heading shortcuts
- Reference Main Description section heading/helper layout

Existing Zelvomart form submission remains unchanged through the hidden `descriptionHtml` field.
