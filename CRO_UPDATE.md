# Zelvomart CRO Dashboard

Added a dedicated `/admin/cro` dashboard.

It uses existing first-party event/order data (no new tracking vendor required) to show:
- Product View → Add to Cart → Checkout → Order funnel
- Conversion rates for each step
- Store conversion rate
- Average order value
- Abandoned-checkout recovery rate
- Revenue/orders by source
- Automatic CRO opportunity hints

The existing Experiments section remains the place to run A/B tests. CRO is the measurement/decision layer; Experiments is the testing layer.
