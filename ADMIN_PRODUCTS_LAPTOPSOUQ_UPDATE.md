# Admin Products – LaptopSouq-style update

- Removed the Admin **Content** page from the sidebar and removed its frontend route. Public content pages/backend page APIs were not removed.
- Rebuilt Admin **Products** screen to follow the LaptopSouq reference:
  - category pill tabs with counts (max 6 primary Zelvomart categories)
  - large search field
  - Add Product, Upload Image Folder and Import CSV actions
  - product image/title/slug table rows
  - category, SKU, price, stock, added date and publish status columns
  - direct edit links
- Added a dedicated `/admin/products/add` product form page instead of opening Add Product in a modal.
- Reworked the product form in a LaptopSouq-style section layout:
  - Basics / title / locked published slug / SKU
  - Product category
  - Short description
  - Rich main description
  - Pricing & stock
  - Up to 5 uploaded/manual images + video URL
  - Publish settings / featured / bundle controls
  - SEO title / meta description / canonical URL
  - Save Draft and Publish footer actions
- Existing product edit page uses the same form and retains variants + product deletion.
- Upload Image Folder matches product folders/files against SKU, slug or product title, uploads images through the existing backend upload endpoint, and attaches up to 5 images to the matched product.
- Existing backend/database structure, product APIs, storefront, cache logic, checkout and SEO behavior are preserved.
