# Admin UI update

- Removed the Orders bulk-status selector / Apply to selected controls.
- Add Product is aligned to the right of the Products heading.
- Product create and common edit flows open in large modal dialogs.
- Category add/edit forms open in modal dialogs.
- Users, redirects and experiments create forms open in modal dialogs.
- Content pages are compact buttons/cards; selecting one opens its edit form in a modal.
- Settings are compact section cards; selecting a section opens only that section in a modal.
- Product form follows the LaptopSouq reference design philosophy: section cards, main/sidebar layout, pricing & stock, content, media, publish and SEO areas.
- Main Description now has a lightweight rich-text toolbar.
- Product variants remain available from the advanced product page and Add Variant opens in a modal.

## LaptopSouq-style sidebar + catalog tools
- Dark navy LaptopSouq-inspired admin sidebar with SVG icons, grouped navigation and white active state.
- Product page action row: Import CSV, CSV Template, Export CSV, Add Product.
- CSV import upserts products by SKU and supports category, pricing, stock, content, images, bundle and SEO fields.
- Product search, category/status filters and compact product thumbnails added.
